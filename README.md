# RuneQuill

RuneQuill is a Cloud-native, containerized platform that enables real-time auto-scaling, and integrates seamlessly with RESTful APIs at runtime.

RuneQuill is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/RuneQuill.git`
2. `cd RuneQuill`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
